## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Real-time Total** | Always-visible display of total scrap value sitting on the ship |
| **Configurable Display** | Adjust the position, font size, and color of the value display |
| **Individual Items** | Optional mode showing value breakdown per item on the ship |
| **Minimal Performance** | Zero gameplay impact — pure HUD overlay with no lag |
